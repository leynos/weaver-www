Near Term

Focus: Stabilization & UX

In Progress

Daemon UX Overhaul

Expected: Aug 2026

Improving the developer experience of the background daemon. Moving from silent failures to rich, actionable status reporting via the CLI.

  • weaver status --watch command
  • Auto-restart on crash policy
  • Better log rotation
  • macOS Menu Bar indicator
High Priority

Fusion Engine v2

Expected: Sep 2026

Enhancing the Semantic Fusion Engine to support multi-repo context blending. Agents will be able to reason across microservices boundaries.

Mid Term

Focus: Ecosystem & Security

Upcoming Major

Jacquard Symbol Cards

Target: Q4 2026

A visual debugging interface for agent cognition. "Cards" represent the agent's internal model of a code symbol, allowing developers to inspect and correct the AI's understanding of their codebase directly.

Planned

Granular Sandbox Policies

Target: Q1 2027

Moving beyond "all or nothing" network access. Define per-domain allowlists for agents (e.g., allow `api.stripe.com` but block everything else) via weaver.toml.

3

Long Term

Focus: Automation & Integration

Headless CI Workflows

Running Weaver agents as part of GitHub Actions or GitLab CI to automatically review PRs, check for architectural drift, and auto-fix lint errors.

Research Phase

Native IDE Plugins

Moving beyond the CLI. Native VS Code and IntelliJ plugins that visualize the Weaver graph directly in the editor gutter and sidebar.

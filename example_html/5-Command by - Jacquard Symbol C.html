Jacquard
Symbol Cards

A structured visual interface for agent cognition. Jacquard cards allow developers to inspect, correct, and reuse the "mental model" an AI agent builds about specific code symbols.

Structured Intent Primitives

Current AI coding tools treat context as a flat wall of text. Jacquard introduces Symbol Cards—discrete, structured units of understanding that encapsulate a function, class, or module's semantic role.

  • Portable Context: Share a "card" representing a complex auth flow between different agents.
  • Human-Verifiable: Inspect the agent's summary and assumptions before it writes code.
  • Living Documentation: Cards automatically update as the underlying code evolves.

Memory Persistence

Agents typically "forget" code structure between sessions. Jacquard cards persist the agent's understanding to disk, creating a long-term memory bank for your project.

Team Alignment

Senior engineers can pre-generate cards for critical modules, adding safety locks and notes. Junior devs (or agents) then use these verified cards as reliable building blocks.

Composable Logic

Treat documentation as code. Cards can be versioned, diffed, and merged, allowing documentation to live in the same commit history as the implementation.

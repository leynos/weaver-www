COMMANDS / OBSERVE

Perception &
Structure.

The observe command is the sensory organ of the Weaver agent. It fuses raw file content with semantic metadata from Tree-sitter and LSP servers to produce a high-fidelity, structured representation of the codebase.

Synopsis

Invokes the Semantic Fusion Engine to parse files or directories. Output is always streamed as JSONL to stdout for easy piping to LLM context windows or analysis tools.

SYNTAX
weaver observe [OPTIONS] <PATH>...
Supports glob patterns (e.g., src/**/*.rs)

Options & Flags

Flag Type Description
--depth Integer Max recursion depth for directory traversal (default: 5).
--symbol String Filter output to a specific function or class name (uses Sempai engine).
--with-lsp Boolean Enrich output with LSP diagnostics, definitions, and references.
--format Enum Output format: jsonl (default), tree, or markdown.
--ignore-hidden Flag Skip hidden files and directories (respects .gitignore).

Integration Examples

1. High-Fidelity Context Gathering

When an agent needs to understand a file, observe provides more than just text. It returns the AST structure, enabling the agent to "see" the code's skeleton.

TERMINAL
$ weaver observe src/auth.rs --with-lsp
JSONL Stream
// Event 1: File Metadata
{
  "type": "file",
  "path": "src/auth.rs",
  "language": "rust",
  "size_bytes": 4096
}
// Event 2: Semantic Symbol
{
  "type": "symbol",
  "name": "AuthService",
  "kind": "struct",
  "range": {"start": 12, "end": 45},
  "provenance": {
    "source": "tree-sitter",
    "confidence": 1.0
  }
}

2. Targeted Sempai Query

Instead of dumping entire files, use --symbol to extract specific functions or classes across the project. This reduces context window usage significantly.

TERMINAL
$ weaver observe . --symbol "connect_db"
JSONL Stream
// Found in main.rs
{
  "type": "match",
  "file": "src/main.rs",
  "signature": "fn connect_db(url: &str) -> Result<PgPool>",
  "snippet": "fn connect_db(url: &str) -> Result<PgPool> { ... }",
  "docstring": "/// Establishes a connection pool."
}
// Found in tests/db_test.rs
{
  "type": "match",
  "file": "tests/db_test.rs",
  "signature": "fn test_connect_db()"
}

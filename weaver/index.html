Sempai Query Engine

To act, the agent must first discern structure. Sempai provides a Semgrep-compatible query layer that allows you to extract features, identify patterns, and map dependencies with surgical precision.

  • Tree-sitter backend for fault-tolerant parsing
  • Support for Rust, Python, Go, and TypeScript
  • Advanced feature extraction for LLM context windows
